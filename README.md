# Jana Bai — Реалити-Проект & Акселератор Селлеров

Официальный лендинг проекта **Jana Bai** (`janabai.kz`).

## Особенности
- Развернут на Vercel для максимальной скорости и безопасности.
- Отправка заявок на единый бэкенд Taobey Buyers (`https://api.buyers.taobey.kz/api/janabai/applications`).
- Единый административный интерфейс для просмотра всех заявок.
- Динамическая публикация постов, дневника проекта и участников.

## Запуск локально
```bash
npm install
npm run dev
```

## Сборка для Vercel
```bash
npm run build
```
